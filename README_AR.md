# VAIROS TOOLBOX — النسخة الأولية

تطبيق Android عربي لعرض أدوات Termux وشرحها وإرسال أوامر التشغيل إلى Termux عبر RUN_COMMAND.

## مهم قبل الاستخدام
- هذا المشروع لا يحتوي كل أدوات Termux؛ كتالوج النسخة الأولى عينة قابلة للتوسيع.
- التطبيق يحتاج تطبيق Termux مثبتًا ومتوافقًا.
- من Termux: Settings → Allow external apps = ON.
- عند أول تشغيل، وافق على طلب الإذن إذا ظهر.
- بعض الأوامر تعرض نتائجها في جلسة Termux، وليست داخل شاشة التطبيق في هذه النسخة.
- زر تثبيت الأدوات في النسخة الأولية يستخدم أسماء حزم Termux؛ بعض أسماء الحزم قد تختلف أو تحتاج تعديلًا.

## بناء APK
أسهل طريقة:
1. ارفع المجلد إلى مستودع GitHub جديد باسم VAIROS_TOOLBOX.
2. افتح تبويب Actions.
3. شغّل workflow المسمى Build Android APK.
4. بعد انتهاء البناء افتح Artifacts ونزّل `VAIROS-TOOLBOX-debug-apk`.

## توصيل Termux
افتح Termux ونفّذ:
```bash
mkdir -p ~/.vairos
pkg update -y
```
ثم افتح إعدادات Termux وفعّل Allow external apps.

## تطوير قادم
- نتائج الأوامر داخل التطبيق عبر قناة تواصل آمنة.
- صفحات تفاصيل كاملة لكل أداة.
- كتالوج موسع يُحدّث من ملف JSON.
- مفضلة وسجل أوامر.
- تصنيف أوامر آمن مع تأكيد قبل الأوامر الحساسة.
